# Shiba-Inu

Игра Shiba-Inu это классический ранер, в котором вам предстоит гнаться за бабочкой, уворачиваясь от ульев и мухоморов в лесу.  Прыжок на клавишу spase очень гибок, и его высота напрямую зависит от продолжительности нажатия, а также для прохождения сложных препятствий предусмотрен двойной прыжок (обратите внимание: второй прыжок немного слабее первого). Генерация объектов случайна, потому вам необходимо каждый раз придумывать способ пройти то или иное препятствие. Скорость игры увеличивается со временем, поэтому вам стоит быть осторожными на поздних этапах. В левом верхнем углу располагается счетчик очков (количество очков равно времени, проведенному в забеге); по окончании забега очки запишутся в таблицу рекордов, если вы превзошли один из лучших десяти свои результатов (не стоит переживать, результаты сохранятся даже если вы выйдете из игры). После забега вы окажитесь в разделе меню. Тут вы можете нажать мышью на надпись PET и выбрать персонажа, который нравится больше всего, а также можете узнать десять своих лучших результатов кликнув на RESULTS в правом верхнем углу (выйти из разделов PET и RESULTS можно кликнув на BACK в правом верхнем углу). Чтобы играть было удобнее, вы можете развернуть игру в полноэкранный режим, а чтобы покинуть игру, вам достаточно просто закрыть окно (красный крестик).

# Установка

1. Создайте папку c именем shiba-inu и клонируйте туда репозиторий.

2. Откройте терминал или окно командной строки в директории src, где находятся файлы игры.

3. Пропишите следующие команды в терминал:
```bash
sudo apt-get update 
sudo apt-get upgrade
pip install -r requirements.txt
```
4. Для запуска игры введите команды: 
```bash
chmod +x main.py
python3 main.py
```
5. Наслаждайтесь игрой.
